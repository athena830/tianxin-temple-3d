## 二、需求來源對照

你這次列的六項，涵蓋需求書的第二階段（入口及庭院、天公爐、問事亭）與第三階段（三門、天公殿、各神明殿）。
建議拆成兩個子步驟，各自測試、各自存檔，出問題時能單獨還原：

- **2A 入口與前庭**：牌樓、石板主路、吊燈籠、許願池改為側邊蓮花許願池、天公爐、天心仙姑問事亭。
- **2B 主殿三門與各殿**：龍門／正門／虎門、天公殿、五座神明殿。

## 三、新的整體配置（依需求書 6.3 配置圖）

以使用者從入口面向主殿為準，左＝西、右＝東。場地由目前 42×54 公尺擴大到約 62×100 公尺。

```
                       【後方】
        天上聖母殿                 福德殿
        文昌殿                     月老殿
                ┌──────────────┐
  五路財神殿     │  觀音佛祖主殿  │     天公殿（玉皇大帝）
                │ 龍門 正門 虎門 │
                └──────────────┘
  天心仙姑問事亭      ║ 石板主路 ║        天公爐
  （六角涼亭）        ║          ║      （前庭參拜區）
  蓮花許願池          ║          ║        蓮花池
  座椅・植栽・燈籠    ║          ║    座椅・植栽・燈籠
                    【入口牌樓】
```

- 石板主路寬 4 公尺，由牌樓直通正門，路面上不放任何物件。
- 問事亭在前庭左側，從入口就看得到，與天公爐左右分開。
- 天公殿在主殿右側，正前方對著天公爐，形成「先拜天公爐、再入天公殿」的動線。

## 四、2A 入口與前庭

| 項目 | 做法 |
|---|---|
| 入口牌樓 | 重建為三開間牌樓，「玉皇宮」匾額，外加兩側石獅座位。 |
| 吊燈籠 | 主路正上方完全淨空；燈籠改掛在牌樓兩側柱旁，高度 4.2 公尺以上，沿路燈籠改為路旁立柱燈。保留第一階段的「擋住鏡頭的裝飾自動隱藏」作為保險。 |
| 許願池 | 從主路中央移除，改成主路左側的「蓮花許願池」，投硬幣功能、紀錄與音效不變。右側對稱放一座觀賞蓮花池。 |
| 天公爐 | 前庭右側。銅製三足大爐、石座、香枝、香煙、燈光。靠近顯示「參拜玉皇上帝」，點擊後人物自動面向天公爐、播放合掌鞠躬動作、顯示祈願文字，完成後恢復移動，並寫入祈福紀錄。 |
| 天心仙姑問事亭 | 前庭左側，開放式六角涼亭：紅柱、木欄杆（留入口）、石地坪、傳統屋頂、「天心仙姑」簷下匾額、亭內桌椅與象棋棋盤。可走進亭內，點擊棋盤開啟原有的象棋卜卦面板，並加上「天心仙姑問事服務介紹」與「正式問事聯絡入口」兩個按鈕（聯絡方式先放預留位置，請你之後提供）。 |
| 植栽與座椅 | 主路兩側植栽、石椅，都放在主路外。 |
| 碰撞 | 涼亭柱子、欄杆、天公爐、蓮花池、牌樓柱都有碰撞；涼亭入口與主路保持可通行。 |

## 五、2B 主殿三門與各殿

| 項目 | 做法 |
|---|---|
| 主殿正面 | 主殿加寬約 24 公尺，正面改為三川門牆，留三個真正的門洞，門洞寬至少 2.4 公尺（人物與鏡頭都能通過）。 |
| 龍門／正門／虎門 | 依需求書 7.2「以使用者面向主殿時的左右方向為準」：左龍門、中正門、右虎門。每門有獨立門框、兩扇木門、低門檻（可跨越）、雕花門楣。靠近時顯示「進入龍門／正門／虎門」，門扇自動向內打開，離開後關上。門牆兩側及門框都有碰撞。 |
| 天公殿（凌霄寶殿） | 主殿右側獨立殿宇，有台基與石階、匾額、神龕、供桌，可走入。 |
| 五座神明殿 | 五路財神殿（左前）、文昌殿（左後）、天上聖母殿（左最後）、月老殿（右後）、福德殿（右最後）。每座都有獨立匾額、神龕、供桌、參拜空間與開放門口，可實際走入。 |
| 神像 | 預設用程式製作 Q 版神像（依各神明的服色與持物區分），不花點數。日後可再換成 AI 生成模型。 |
| 參拜指引 | 新增天公爐、問事亭、天公殿、五座殿與三門為目的地，仍用金色箭頭引導，不傳送。 |

各神明殿的參拜互動（上香、介紹等）依需求書屬於之後階段，2B 只做到「可辨識、可進入、有名稱、有碰撞」。

## 六、原有功能搬遷（功能本身不改）

主殿兩側原本是開放空地，2B 要在那裡蓋五路財神殿與天公殿，所以原有設施只搬位置：

| 設施 | 目前位置 | 新位置 |
|---|---|---|
| 上香、供奉、寫下心願、觀音像 | 主殿內 | 不動 |
| 每日抽籤 | 主殿左外側 | 主殿內左側 |
| 木魚 | 主殿右外側 | 主殿內供桌旁 |
| 平安燈／財神燈／文昌燈 | 主殿右外側 | 主殿內右側 |
| 象棋卜卦 | 主殿左外側 | 天心仙姑問事亭（2A） |
| 祈福鐘 | 主殿右外側 | 前庭右側鐘亭 |
| 祈願牆、祈福紀錄 | 右側圍牆 | 前庭右側圍牆 |

祈福資料、紀錄格式和面板內容都不改，本機已存的紀錄可以繼續讀取。

## 八、驗收方式

每個子步驟完成後，自動測試都會檢查：

- 第一階段 35 項全部仍通過。
- 從入口沿主路走到正門，不傳送，主路上沒有任何阻擋。
- 三個門都能實際走進走出，門牆無法穿越。
- 天公殿與五座殿都能走入，名稱正確。
- 問事亭可走入，點擊棋盤開啟象棋卜卦。
- 天公爐參拜流程完整，並寫入紀錄。
- 所有原有祈福互動在新位置仍可使用並寫入紀錄。
- 桌面、手機直向與橫向的截圖檢查。
