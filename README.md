# 天心宮 / 玉皇宮 3D 線上宮廟與靈光市集元宇宙系統（VER 3.71.6）

基於 **Three.js + Rapier 3D 物理引擎 + TypeScript** 打造的沉浸式線上 3D 宮廟與 2.5D 靈性市集雙世界元宇宙。香客除了能在宮廟內自由漫遊、體驗正統台灣宮廟參拜儀軌與天心仙姑象棋卜卦外，還能穿越時空門前往「**天心靈光市集（天空之城 × 台式霓虹）**」體驗紫微斗數、靈氣療癒、靈光牌卡占卜、人類圖與生命靈數，或跨域傳送至「**月光森林・獨角獸聖域**」。

## 核心特色與三大空間模組

### 1. 玉皇宮 / 天心宮 3D 聖境（`TempleWorld`）
- **正殿三聖同祀與專屬跪拜蒲團**：中央主祀**觀世音菩薩**，龍邊陪祀**天官武財神**，虎邊陪祀**月下老人**；殿內配置 6 座玩家專屬朱紅鑲金拜墊，點擊即可自動走上拜墊合十跪拜與敬香。
- **後殿凌霄寶殿（全平面無障礙三川三門連通）**：二進最高規制殿宇供奉**玉皇上帝（玄穹高上玉皇大天尊）**；二層重簷明樓高懸「凌 霄 寶 殿」金字主匾（`y = 7.6m`），正殿左門（通天）與右門（達地）具 5.13m 超寬無柱走道與全平面無縫石台基，筆直暢通直達玉皇上帝御前。
- **天心仙姑問事亭（PDF 標準象棋卜卦引擎）**：嚴格遵循 32 顆實體象棋索引、單卦十字五星排盤、十字吃子捕捉規則、保護免吃與好朋友減半機制，完整內建 **17 大格局家族與仙姑原文辭典**，支援一鍵複製卦象摘要與 LINE 官方預約解卦。
- **西側五層樓高昇龍觀音聖境**：穿過西牆「昇龍聖境」月亮門與松林石燈古道，登上直徑 28m 漢白玉八角大平台，仰望 15 米高 Q 版白衣乘龍觀音金身與螺旋升騰神光。
- **祈福天燈、廣場祈願牆、盛景蓮花池與八角金亭**：問事亭旁設祈福天燈台（點燃孔明燈冉冉升空）；大殿外廣場東側設歇山瓦頂「祈願牆」；東翼設 10.4m × 7.4m 皇家園林級「盛景蓮花許願池」；西翼設「八角金亭」化金祈福，並具備晨鐘暮鼓、七星光明燈、木魚與每日靈籤。
- **全區自動尋路導航（`planGuidePath`）與 20 位自主漫遊 NPC**：點選「參拜指引」任一設施，角色自動規劃跨區路徑前往；場內 20 位信眾香客由山門牌樓自然步行進出，並依所在分區觸發情境感知對話泡泡與底部字幕。

### 2. 天心靈光市集 — 天空之城 × 台式霓虹 2.5D 場景（`MarketWorld`）
- **天空之城浮空島嶼 × 台式低面數霓虹美學**：由前庭東側「靈光時空門」或頂部「進入市集」按鈕無縫切換。主市集街道矗立於雲海之上的古代石造天空露台，四周環繞 6 座拉普達風格浮空島嶼、發光飛行石水晶核心、藤蔓古樹與雙層動態雲海。
- **同步台中即時真實天氣（Open-Meteo Live Weather）**：自動串接台中座標（`24.1477°N, 120.6736°E`）即時氣象資料（每 10 分鐘更新），動態切換晴空、多雲或雨夜霓虹粒子特效與路面濕潤倒影，並於頂部顯示即時氣溫與天氣狀態。
- **四大獨立靈性攤位與完整命理引擎**：
  1. **紫微斗數（Ziwei）**：內建完整紫微斗數命盤排盤引擎（`src/game/ziwei-engine.ts`），支援輸入出生年月日時辰排算命宮、十二宮位與主星解析，並於本機保存命盤。
  2. **靈氣療癒 & 人類圖（Reiki / Human Design）**：結合七脈輪能量引導與人類圖（`src/game/human-design-engine.ts`）類型、權威與能量中心解析。
  3. **塔羅／靈光牌卡占卜（Tarot / Card）**：提供「每日一卡」與「三卡主題牌陣」（`src/game/card-engine.ts`），搭配柔和發光水晶球攤位互動。
  4. **問事／心靈諮詢**：串接天心仙姑象棋卜卦與 LINE 官方一對一預約諮詢。
- **360° 自由旋轉與一鍵「平視攤位」視角**：支援滑鼠右鍵／觸控 360° 無死角環繞旋轉，並於頂部提供 **「👁️ 平視攤位 / 俯視全景」** 一鍵切換與視角重置按鈕。

### 3. 月光森林・獨角獸聖域跨站雙向連結（`Unicorn Sanctuary`）
- 於天心宮前庭西側設立紫金星光「**獨角獸時空門**」（`x = -23.8, z = 14.2`），並於頂部 HUD 常駐 **「🦄 獨角獸聖域」** 快捷按鈕與參拜指引導航。
- 點擊或踏入時空門可開啟跨界傳送門前往「**月光森林・獨角獸心安宮**」（`https://athena830.github.io/unicorn-sanctuary/?from=tianxin-temple`），體驗神聖獨角獸靈籤與靈氣森林，並支援雙向傳送返回天心宮。

### 4. 智慧音訊銜接系統（`AudioManager`）
- 頂部配置溫潤奶油白膠囊音樂按鈕，支援「綠度母心咒」與 12 首靜心曲目切換及唱誦計數，並將使用者靜音偏好持久化於 `localStorage`（`userMuted`）。
- 進入「天心靈光市集」時自動執行 **1.2 秒平滑指數淡出並暫停背景音樂（BGM）**，僅保留互動音效；返回玉皇宮時依使用者靜音記憶智慧決定是否恢復播放。

## GitHub Pages 線上網站設定指南

線上參拜網址：`https://athena830.github.io/tianxin-temple-3d/`

若開啟頁面為空白，原因為 GitHub 預設讀取了 `main` 分支未編譯的 TypeScript 源碼檔案。請依下列任一方式完成設定即可正常開啟：

### 推薦方式 A：設定為 gh-pages 分支（已就緒，10 秒完成）
1. 前往 GitHub 儲存庫設定：`https://github.com/athena830/tianxin-temple-3d/settings/pages`
2. 在 **Build and deployment** 區塊：
   - **Source**：選擇 `Deploy from a branch`
   - **Branch**：由 `main` 切換為 **`gh-pages`**，資料夾保持 **`/(root)`**
3. 點擊 **Save**。等待 30 秒至 1 分鐘重新整理網頁即可正常暢遊！

### 方式 B：設定為 GitHub Actions 自動 CI/CD 部署
1. 前往 GitHub 儲存庫設定：`https://github.com/athena830/tianxin-temple-3d/settings/pages`
2. 在 **Build and deployment** 區塊：
   - **Source**：下拉改選為 **`GitHub Actions`**
3. 儲存庫內已配置 `.github/workflows/deploy.yml`，日後每次推送代碼至 `main` 分支時，GitHub 將自動建置並發布最新版本。

## 快速啟動與開發測試指令

```bash
# 1. 啟動開發預覽伺服器 (預設連接埠: 3000)
npm run dev
# 或指定連接埠：
npx vite --host 127.0.0.1 --port 3000

# 2. 執行 TypeScript 型別檢查與單元測試套件 (Vitest，共 17 個測試檔、108 項自動化測試)
npm run typecheck
npx vitest run --exclude "**/preview.test.mjs"

# 3. 生產環境打包與一鍵部署至 GitHub Pages
npm run build
npm run deploy:gh-pages
```
瀏覽器開啟：`http://127.0.0.1:3000/`

## 操作指引

### 1. 玉皇宮 / 天心宮 3D 聖境
- **滑鼠左鍵點擊地面 / 設施**：角色自動平穩邁步走向點擊位置（支援點擊地面漫遊、點擊設施或大殿紅拜墊自動靠近並觸發祈福）
- **WASD / 方向鍵**：鍵盤自由移動（隨時無縫覆蓋滑鼠自動導航）
- **Shift**：快速奔跑
- **滑鼠右鍵拖曳 / 觸控右側滑動**：自由旋轉 3D 視角與仰俯角
- **滾輪 / 雙指縮放**：縮放鏡頭遠近距離
- **E 鍵 / 點擊設施**：進行上香、跪拜蒲團、天燈祈福、象棋卜卦、點燈、化金與朝拜互動
- **頂部快捷導覽列**：
  - **⏰ 時段切換**：支援跟隨現實時間（含農曆月相）或手動切換晨曦、白天、夕陽、夜晚
  - **🎵 背景音樂**：奶油白膠囊按鈕一鍵切換播放／靜音，或切換 12 首靜心曲目
  - **進入市集**：一鍵傳送至「天心靈光市集」（或步行穿過前庭東側「靈光時空門」）
  - **🦄 獨角獸聖域**：開啟跨界傳送門前往「月光森林・獨角獸心安宮」（或步行至前庭西側「獨角獸時空門」）
  - **參拜指引 / 祈願牆 / 祈福紀錄**：一鍵自動尋路前往全區任一殿堂設施、書寫祈願或匯出備份紀錄

### 2. 天心靈光市集（天空之城 × 台式霓虹 2.5D 模式）
- **滑鼠左鍵點擊街道地面 / 攤位熱區**：角色自動沿市集街道平滑移動；點擊攤位招牌或店面直接開啟「紫微斗數」、「靈氣療癒／人類圖」、「塔羅牌卡占卜」或「問事諮詢」介面
- **WASD / 方向鍵**：鍵盤控制角色於街道與天空露台自由漫步
- **滑鼠右鍵拖曳 / 觸控雙指拖曳**：**360° 全視角自由旋轉**與調整俯仰高度（可環視周圍天空之城浮空群島、底部飛行石水晶與雲海）
- **👁️ 平視攤位 / 俯視全景按鈕**：點擊頂部「👁️ 平視攤位」按鈕可一鍵切換至水平正視攤位招牌與水晶球的視角；點擊「🔄 重置視角」可回到標準 2.5D 視角
- **⛩️ 返回天心宮**：點擊頂部「⛩️ 返回天心宮」按鈕或走向街道左側朱紅鳥居即可返回玉皇宮前庭（自動恢復背景音樂設定）
