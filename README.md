# 天心宮 / 玉皇宮 3D 線上宮廟參拜系統

基於 Three.js + Rapier 3D 物理引擎打造的沉浸式線上 3D 宮廟空間。香客可以自由穿過牌樓前庭漫遊參拜，體驗天公爐上香、觀音佛祖主殿禮拜、天心仙姑問事亭象棋卜卦、點光明燈、蓮花許願池投幣祈福等豐富互動。

---

## GitHub 儲存庫與多人協作

本專案主要的官方協作 GitHub 儲存庫為：
- **Repository URL**：`https://github.com/athena830/tianxin-temple-3d.git`
- **主要分支**：`main`

### 常用協作指令
```bash
# 1. 抓取並合併遠端協作者最新變更（附帶所有版本標籤）
git pull origin main --tags

# 2. 推送本機開發內容與標籤至共同儲存庫
git push origin main
git push origin --tags

# 3. 部署最新打包成果至 GitHub Pages（gh-pages 分支）
npm run deploy:gh-pages
```

## GitHub Pages 線上網站設定指南

線上參拜網址：`https://athena830.github.io/tianxin-temple-3d/`

若開啟頁面為空白，原因為 GitHub 預設讀取了 `main` 分支未編譯的 TypeScript 源碼檔案。請依下列任一方式完成設定即可正常開啟：

### 推薦方式 A：設定為 gh-pages 分支（已就緒，10 秒完成）
1. 前往 GitHub 儲存庫設定：`https://github.com/athena830/tianxin-temple-3d/settings/pages`
2. 在 **Build and deployment** 區塊：
   - **Source**：選擇 `Deploy from a branch`
   - **Branch**：由 `main` 切換為 **`gh-pages`**，資料夾保持 **`/(root)`**
3. 點擊 **Save**。等待 30 秒至 1 分鐘重新整理網頁即可正常暢遊！

### 方式 B：設定為 GitHub Actions 自動 CI/CD 部署
1. 前往 GitHub 儲存庫設定：`https://github.com/athena830/tianxin-temple-3d/settings/pages`
2. 在 **Build and deployment** 區塊：
   - **Source**：下拉改選為 **`GitHub Actions`**
3. 儲存庫內已配置 `.github/workflows/deploy.yml`，日後每次推送代碼至 `main` 分支時，GitHub 將自動建置並發布最新版本。

## 操作指引

- **探索模式**：
  - **滑鼠左鍵點擊地面 / 設施**：角色自動平穩邁步走向點擊位置（支援點選地面漫遊與點擊設施自動靠近祈福）
  - **WASD / 方向鍵**：鍵盤自由移動（隨時無縫覆蓋滑鼠導航）
  - **Shift**：快速奔跑
  - **滑鼠右鍵拖曳 / 觸控右側滑動**：旋轉 3D 視角
  - **滾輪**：縮放鏡頭距離
  - **E 鍵 / 點擊設施**：進行參拜與儀式互動
  - **Esc**：關閉目前面板 / 退出探索模式
- **自由模式 (Browse)**：
  - 可直接使用滑鼠點擊畫面上方的「參拜指引」、「祈願牆」或「祈福紀錄」。
